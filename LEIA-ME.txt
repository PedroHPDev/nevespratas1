PACOTE INCREMENTAL — NEVES PRATAS

Este pacote contém somente os arquivos alterados e as fotos novas/corrigidas necessárias para atualizar o catálogo existente.

Envio:
- Substitua os arquivos de código na raiz do repositório: index.html, app.js, style.css, collections.css e products.js.
- Copie as imagens .webp deste pacote também para a raiz do repositório, junto das imagens NP que já existem.
- Não crie a pasta fotos para este pacote: o products.js foi ajustado para usar os nomes NP-xxx.webp na raiz, compatível com o repositório atual.

O catálogo inclui 257 produtos, com a seção feminina e os preços comerciais ajustados.
